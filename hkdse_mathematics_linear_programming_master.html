Linear Programming Essential Notes

Core rules and marking scheme concepts for HKDSE Compulsory Mathematics.

1

1. Feasible Region (可行區域)

The common shaded region satisfying all system constraints simultaneously. Includes non-negativity $x \ge 0, y \ge 0$. Must use solid lines for $\le, \ge$ and dashed lines for $<, >$.

2

2. Fundamental Theorem

If a feasible region is **bounded** (a closed polygon), the maximum and minimum values of $Z = ax + by$ **MUST occur at one of the vertices (corner points)**.

3

3. Search Line Method (平行線法)

Move the line $ax + by = Z$ parallel across the region. The last point touched before leaving the feasible region gives the Maximum (or Minimum depending on slope).
